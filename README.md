# 🎧 MusicVerse

## 📌 Descripción
MusicVerse es una plataforma musical creada para descubrir canciones, explorar diferentes géneros y conocer nuevos artistas. Su objetivo es ofrecer una experiencia sencilla y moderna para los amantes de la música.

## 🎯 Objetivo
Promover el descubrimiento musical y facilitar el acceso a recomendaciones de canciones y artistas según los gustos de cada usuario.

## ✨ Funciones principales
- Explorar géneros musicales.
- Descubrir artistas.
- Conocer recomendaciones musicales.
- Organizar canciones en playlists.

Géneros musicales

MusicVerse reúne diferentes estilos musicales para todos los gustos:

🎸 Rock: guitarras y sonidos intensos.

🎤 Pop: canciones populares y melodías pegadizas.

🎧 Hip-hop: ritmo, rimas y expresión urbana.

🎹 Electrónica: sonidos digitales y ritmos modernos.

🎷 Jazz: improvisación y creatividad musical.

🎶 Reguetón: ritmos urbanos latinos.

## 📀 Playlists recomendadas

- **Chill Vibes:** música tranquila para relajarse.
- **Energy Mode:** canciones con energía para animarse.

- **Latin Mix:** una selección de música latina.
