# 🎧 MusicVerse

## 📌 Descripción
MusicVerse es una plataforma musical creada para descubrir canciones, explorar diferentes géneros y conocer nuevos artistas. Su objetivo es ofrecer una experiencia sencilla y moderna para los amantes de la música.

## 🎯 Objetivo
Promover el descubrimiento musical y facilitar el acceso a recomendaciones de canciones y artistas según los gustos de cada usuario.

## ✨ Funciones principales
- Explorar géneros musicales.
- Descubrir artistas.
- Conocer recomendaciones musicales.
- Organizar canciones en playlists.
